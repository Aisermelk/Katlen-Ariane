# Katlen Ariane — V8 Digital

Página estática em HTML/CSS/JS, preparada para GitHub + Cloudflare Pages e integração com o V8 Admin Universal.

## Configuração
No final de `index.html`, troque `SEU_PROJECT_ID` pelo ID do projeto criado no V8 Admin Universal. O `data-api-url` já aponta para o Worker V8.

O `js/v8-loader.js` é o loader fornecido para este projeto. Campos `data-v8` podem ser controlados pelo painel conforme a configuração pública do projeto.
